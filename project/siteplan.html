Stanway Poultry Feed Guide

Website Planning Document

1. Site Name

Stanway Poultry Feed Guide

I chose the name Stanway Poultry Feed Guide because the website will provide practical information about poultry feed and feeding. The name is simple, easy to remember, and clearly tells visitors what the website is about.

Optional domain: stanwaypoultryfeed.com

2. Site Purpose

The purpose of this website is to help poultry farmers and beginners understand poultry feed, feeding practices, and basic feed formulation. The site will provide information about different types of poultry feed, useful feeding tips, common ingredients, and ways farmers can make better feeding decisions while managing feed costs.

3. Scenarios

These are questions that visitors to the website may have:

  • What type of feed should I give my broiler chickens at different stages of growth?
  • How can I reduce poultry feed costs without negatively affecting bird growth?
  • What ingredients are commonly used when formulating poultry feed?
  • How much feed should I provide to my chickens each day?

5. Typography

Roboto Slab

Roboto Slab will be used for the main headings and section headings. It gives the website a strong and professional look.

Example Heading: Poultry Feed Information

Roboto

Roboto will be used for paragraphs, lists, navigation text, and other general content because it is clean and easy to read.

Example body text: Good feeding practices can help poultry farmers manage costs and support healthy bird growth.
